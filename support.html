Support

ImageSage supports Windows 11 x64, build 22000 or later, and local PNG, JPEG, and WebP files.

Contact ImageSage support

Email support@ringlochid.me. Include the ImageSage version, Windows version, what you did, and the visible error message.

Compose support email

Before reporting a problem

  • Confirm that the folder still exists and your Windows account can read it.
  • Open Settings and use Import again for an unavailable folder source.
  • Allow preparation to finish before judging OCR or visual-search completeness.
  • Install the latest ImageSage update from Microsoft Store and restart the app.

Protect your private content

Do not attach original photos, recognized text, private filenames or paths, databases, credentials, or secrets. ImageSage does not automatically attach diagnostics or library content to an email.

Report an AI-generated suggestion

Magic Rename suggestions can be inaccurate or inappropriate. Nothing changes until you confirm a name. Report only the generated words, the ImageSage version, and a general non-identifying description of the image category.
